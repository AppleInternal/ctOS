# ctOS OneCore
## Инструкция по сборке системы:
1. добавьте нужные пакеты в packages (по желанию)
2. ```sudo ./newiso.sh``` !!требует genisoimage и tar!!

## Пояснение за скрипты:
```./packages/prepare_rootfs.sh``` устанавливает пакеты и родготавливает rootfs 
```./newiso.sh``` собирает iso и подготавливает rootfs


## Для разработчиков софта:
Готовые пакеты кидайте в packages, именно так они попадут в систему
